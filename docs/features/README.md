# Kartu Fitur (`docs/features/`)

Folder ini memuat spesifikasi **fitur lintas modul** yang menyatukan beberapa crate/aplikasi menjadi kemampuan utuh yang dirasakan pengguna (misalnya pengiriman transaksi dari wallet ke node atau pemantauan pembayaran *watch-only* di merchant).

## Format Identitas

- **Format ID:** `FTR-xx` (dua digit berurutan, misalnya `FTR-01`, `FTR-02`)
- **Format Nama Berkas:** `FTR-xx-<slug>.md`
- **Aturan Ketergantungan:** Task fitur (`FTR`) hanya boleh dikerjakan setelah seluruh task modul (`MOD`) yang menjadi prasyaratnya selesai dan teruji.
